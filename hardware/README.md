# hardware/

Фізичні частини проєкту. Вимоги й обґрунтування описані в [docs/hardware-and-safety.md](../docs/hardware-and-safety.md)
і [docs/robot.md](../docs/robot.md).

| Тека | Що тут буде |
| --- | --- |
| `gripper/` | CAD (STEP + STL) пальців захвату під фігурки Root |
| `supply_tray/` | лоток запасу воїнів бота з гніздами |
| `camera_mount/` | кріплення камери над столом |
| `layout/` | фото та схема розміщення робота, дошки, камери, упорів дошки |

Для кожної деталі вказуємо: матеріал, параметри друку, дату, версію. Старі версії не видаляємо, а нумеруємо (`v1`, `v2`).
