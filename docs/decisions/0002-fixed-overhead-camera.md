# 0002. Фіксована камера над столом (а не на руці)

- **Статус:** запропоновано (підтвердити після перших тестів на етапі 0)
- **Дата:** 2026-10-22

## Контекст

Камеру можна закріпити над столом (eye-to-hand) або на фланці робота (eye-in-hand).

## Рішення

Основна камера фіксована над дошкою. Камера на руці — лише якщо точності фіксованої не вистачить
для захвату.

## Чому

- Видно всю дошку одним кадром, не треба «облітати» її рукою перед кожним ходом.
- Калібрування простіше: гомографія за малюнком дошки на кожному кадрі (без маркерів, див.
  [0003](0003-markerless-board-detection.md)) плюс одне 2D-перетворення дошка → робот.
  Повне hand-eye калібрування не потрібне.
- Камера не рухається, тому кадри для датасету стабільні.

## Мінуси

- Рука перекриває дошку, тому знімаємо тільки в home-позиції.
- Потрібне кріплення (штатив чи профіль) ~1 м над столом.
- Точність позиції фігурки обмежена роздільністю: ~0.5–1 мм/піксель для 1080p на дошку завширшки ~70 см.
  Для захвату цього має вистачити.
