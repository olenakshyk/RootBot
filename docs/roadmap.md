## Етап 2: Інтеграція (тижні 7–10, 03.12 – 30.12)

Мета: один повний хід бота від початку до кінця.

- [ ] 🔗 Повний хід бота: кадр → стан → дії → рухи → перевірка
- [ ] 🔗 UI оператора: підтвердити чи виправити стан, кубики, карта наказу
- [ ] 👁️ Пошук вільного місця в галявині, перевірка після place
- [ ] 👁️ Розпізнавання карти наказу (або ручне введення як fallback)
- [ ] 👁️ Якщо колір не дає ≥ 95%: датасет + YOLO
- [ ] 🦾 Лоток запасу, зняття втрат у запас
- [ ] 🦾 Обробка помилок: невдалий захват, повтор, зупинка

> 🎄 Канікули: тижні 9–10 можуть бути неповними. Заплануйте заздалегідь, хто коли доступний.

**Демо етапу:** повний хід бота на реальній дошці з реальною розстановкою.
